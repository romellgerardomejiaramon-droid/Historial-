# Historial-

El código está formado por la clase Pila, que se encarga de guardar las direcciones de los sitios visitados. Dentro de esta clase se encuentran los métodos apilar(), que agrega un sitio nuevo; desapilar(), que elimina el último sitio guardado para regresar al anterior; cima(), que muestra el sitio actual; esta_vacia(), que revisa si hay sitios guardados, y mostrar(), que enseña todos los sitios del historial en la terminal. También cuenta con la función main(), donde se encuentra el menú con cinco opciones que permiten visitar un sitio, regresar al anterior, consultar el sitio actual, mostrar el historial completo y salir del programa. Además, se utiliza time.perf_counter() para medir cuánto tarda cada operación, sin contar el tiempo que el usuario pasa escribiendo las opciones o las direcciones. Al ejecutar el código, las instrucciones print() muestran el menú y los resultados en la terminal, mientras que input() permite que el usuario escriba las opciones y los enlaces. Cada vez que se visita un sitio, este se agrega a la pila y se muestra cómo queda organizada, colocando arriba el sitio más reciente. Si se elige regresar, el último sitio se retira y se muestra el anterior, mientras que la opción de ver el historial permite consultar todos los sitios que todavía están guardados. Finalmente, al seleccionar la opción 5, el programa termina y muestra el tiempo total de las operaciones realizadas junto con el mensaje «Fin del programa».
