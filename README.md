# Historial-

El código está compuesto por la clase Pila, que utiliza una lista para guardar las direcciones de los sitios visitados, y los métodos apilar( ), que agrega sitios; desapilar( ), que retira el último sitio; cima( ), que muestra el sitio actual; esta_vacia( ), que comprueba si la pila está vacía, y mostrar( ), que enseña todos los sitios guardados. También cuenta con la función main( ), que controla el menú principal y las cinco opciones para visitar sitios, regresar al anterior, ver el sitio actual, mostrar el historial completo y salir del programa. Además, utiliza time.perf_counter( ) para medir el tiempo que tarda cada operación y acumularlo. Al ejecutar el archivo, el menú aparece en la terminal gracias a las instrucciones print(  ) y permite al usuario escribir sus opciones mediante input( ). Cada vez que se realiza una operación, la terminal muestra el resultado y el estado de la pila; finalmente, al elegir la opción 5, aparecen el tiempo total acumulado y el mensaje «Fin del programa».
